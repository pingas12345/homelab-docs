# Management & Utility Tools

Tools used for container management, monitoring, notifications, dashboards, and general operations.

## Core Management

- **Portainer** - Primary Docker management interface (currently managing 30+ containers)
- **Watchtower** - Automated container update assistance
- **Homepage / Glance** - Service dashboards

## Notifications & Utilities

- **NTFY** - Push notification service
- **Notifiarr** - Notification and integration helper
- **Termix** - Web-based server management / terminal access
- **QDirStat** - Disk usage visualization
- **Crafty Controller** - Minecraft server management
- **Syncthing** - File synchronization
- **QNAP NAS** - Network storage integration

## Skills Demonstrated

- Centralized container management
- Operational visibility and dashboards
- Notification and alerting patterns
- Disk and storage awareness
- Supporting tooling for day-to-day administration
